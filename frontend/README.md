# NovaStore · Auth-service

Front Angular de création de compte, basé sur les couleurs et la typographie de la maquette Stitch.

Démarre Auth-service sur le port 8081. Avec Node.js et npm installés, exécute depuis ce dossier :

```powershell
npm install
npm start
```

Ouvre http://localhost:4200. Le serveur Angular redirige les appels à /api/users vers Auth-service. Lance `npm run build` pour compiler le front.
